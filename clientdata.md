# Client Marketing Intake Pack

What to ask the client for so EXORA can onboard **Client → Brand → Product**, build a brand kit, and produce posts and reels. Use only real facts. Leave blank or write **No offer** / **None** — do not invent prices, proof, rankings, or testimonials.

Suggested PDF title: **`[Brand] — Marketing intake pack`**

Short ask to send with this pack:

> Please fill this intake pack and attach logo, brand guide (if any), 5–10 past posts, and price list. Use only real prices and offers. If there is no offer, write “No offer”. Leave blank what you don’t have — don’t invent claims or rankings.

---

## 1. Cover / who this is for

- Client / company legal name
- Brand name as customers see it (if different)
- Date filled
- Person filling the form (name, role, phone, WhatsApp, email)
- Person who **approves posts** (name, role, WhatsApp/email)

---

## 2. Company (client account)

| Field | Ask for |
| --- | --- |
| Company name | Legal / trading name for the account |
| Industry | e.g. textile and garment manufacture, dental clinic |
| City | HQ / main market city |
| State / region | Karnataka, Maharashtra, Tamil Nadu, Delhi NCR, Other |
| City tier | Tier 1 / 2 / 3 (if they know) |
| Website | Full URL |
| Content languages | e.g. English, Hindi, Hinglish, Kannada |
| Notes | Anything important about the account (not product claims) |

---

## 3. Brand (customer-facing identity)

*One section per brand if they have more than one.*

| Field | Ask for |
| --- | --- |
| Brand name | Exact spelling / casing as used in ads |
| Different industry? | Only if this brand differs from the company |
| Brand website / Instagram | Links |
| One-line what the brand does | Elevator pitch |
| What makes you different | USP — no invented rankings |
| Mission / values | Short, if they have them |
| Primary marketing channels | Instagram, Google, WhatsApp, ads, etc. |

---

## 4. Brand kit & look (for design + reels)

*Critical for posts and video.*

### 4A — Files to attach (or list with links)

- **Logo** — square / mark preferred (PNG, JPEG, WebP, SVG). Not a visiting card or landscape photo
- **Wordmark** if separate from the mark
- Brand guidelines PDF / deck (if any)
- Colour swatches or hex codes
- Font names (heading + body), or font files if licensed for use
- 5–10 past posts that “sound like us”
- Any pattern / motif they always use (optional)

### 4B — Written brand rules

| Field | Ask for |
| --- | --- |
| Colours | Paper (background), Ink (text), Accent (highlight) — hex if possible |
| How it sounds | 3–5 words + a short paragraph (tone of voice) |
| Who it’s for | Primary customer in plain language |
| Words we **never** say | One per line |
| Words we **like** to use | One per line |
| Fine print / disclaimers | Lines that must appear on ads |
| Sample posts | 3–5 real captions or lines that sound right |
| Instagram handle | @… |
| Name shown when there’s no logo | Wordmark text |

### 4C — Optional visual preferences

- Corners: sharp / soft / round
- Feel: calm / balanced / punchy (for reels)
- Always include / never include (layout rules)

---

## 5. Products & services

*One block per product or service. Repeat as needed.*

| Field | Ask for |
| --- | --- |
| Product / service name | Offer name (not the brand name) |
| What it is | 1–2 sentences |
| Category | e.g. Saree, Kids check-up |
| Sector | e.g. Apparel, Healthcare |
| Who buys it | Audience, need, location / buying context |
| Price or current offer | Real only — or write **No offer** |
| Main selling points | One per line |
| Variants | Sizes, colours, packs — one per line |
| Where it is sold | Store address, website, Amazon, Meesho, etc. |
| Proof for claims | `claim \| source \| date` — skip if none; do not invent |

## 7. Marketing operations

| Field | Ask for |
| --- | --- |
| Monthly package preference | Starter / Growth / Content only (if you use packages) |
| Goal for next 30–90 days | e.g. more direction requests, more walk-ins |
| Areas / localities served | For “find us” / local content |
| Opening hours / store landmarks | For location content — real landmarks only |
| Competitor names they care about | Optional |
| Past ads that worked / failed | Optional notes or screenshots |
| Access they will grant later | Instagram, Meta Business, Google Business, Ads, Analytics (list; credentials later, not in this pack) |

---

## 8. Questionnaire answers

*Same seven asks as the WhatsApp questionnaire in the app.*

1. Main services / products (one per line)
2. Price range and any **current** offer (only if real)
3. Who buys from you most?
4. City / areas you serve
5. Instagram + website links
6. Who approves posts from your side? (name)
7. Anything we should never say?

---

## 9. Attachments checklist

Ask them to attach or share:

- [ ] Logo (square mark)
- [ ] Brand guide / deck / colour sheet
- [ ] Font list or licensed font files
- [ ] 5–10 past posts (PDF export, screenshots, or Drive link)
- [ ] Price list / menu
- [ ] Product photos (optional, labelled)
- [ ] Store / location photos (optional)
- [ ] Any legal disclaimer text

**Do not ask them to put passwords in this pack.** Access is arranged separately.

---

## 10. Declaration

- All prices, offers, and claims in this document are true and current.
- If there is no offer, we have written **No offer**.
- We have not invented testimonials, rankings, or numbers.
- Signature / name / date of the approving contact

---

## Minimum vs full pack

### Minimum to start work in the app

- Company: name, industry, city
- Brand: name
- Brand kit: logo or colours + short voice
- At least one product: name + short description

### Full pack (best for strategy + visuals + reels)

Everything in sections 2–9, especially: logo, colours, never-say list, approver, real offer or “No offer”, product proof lines, past posts.

---

## How this maps in EXORA

Tree order: **Client → Brand → Product**.

| Level | Complete when |
| --- | --- |
| Client | Name + industry + city |
| Brand | Name + industry + city **and** a brand kit |
| Product | A product description |

Products inherit the parent brand’s look and voice. Strategy, calendar, and content are drafted on the node you select. Invoices sit at company level only. A visiting card is not a logo — use a square mark, or leave logo empty so designs use the wordmark.
